# Smart Reader v2 Preview 0.1.0

This is an early preview of the React-based v2 reader. It is published alongside the existing root application so people can review the new implementation and its portable edition.

## Included

- A reader foundation for Markdown, semantic HTML, and DOCX books, with source-page markers, headings, footnotes, and citations.
- A local library, contents and passage navigation, search, and links to passages.
- A standalone portable HTML edition with a demonstration book.
- An optional local companion for connecting explicitly shared books to Claude Desktop and Codex.

## Preview limitations

- Browser, mobile-device, representative-book, offline, and persistence acceptance checks are still in progress. See [`docs/release-readiness.md`](../docs/release-readiness.md) and [`docs/v2-rebuild/09-user-review-triage.md`](../docs/v2-rebuild/09-user-review-triage.md).
- The portable edition stores each reader's library in that browser's local storage. Sharing the HTML file does not share book data, and saving from a file opened directly may vary by browser.
- Some online search actions require an internet connection. Optional cloud questions require the reader's own provider API key.
