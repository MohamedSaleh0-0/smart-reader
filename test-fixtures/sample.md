# اختبار القارئ الذكي

**المؤلف:** فريق الاختبار

## الفصل الأول: القراءة والبحث

[ص: ١٢] القراءة المنهجية تجمع بين فهم النص، وتسجيل الفائدة، والرجوع إلى المصدر.

### قائمة الفوائد

- الفائدة الأولى: ترتيب الأسئلة.
- الفائدة الثانية: حفظ موضع النص.
- الفائدة الثالثة: مراجعة المصدر.

يمكن زيارة [رابط تجريبي](https://example.com) أثناء اختبار الروابط.

[^1]: حاشية قصيرة لاختبار Markdown.
